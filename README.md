## 🌟 Key Features

- 🤖 **Authentic Student Roleplay (23 Students)**: Deep, in-character conversations with Blue Archive students configured with detailed lore, relationships with other students, Sensei dynamics, and quote patterns.
- ⚡ **Pluggable High-Speed AI Engine**: Default integration with **Groq** for instantaneous replies and cutting-edge open models (e.g. `openai/gpt-oss-120b`, `qwen/qwen3.8-27b`), plus seamless support for **Google Gemini**, **OpenAI-compatible**, and **Anthropic Claude** APIs.
- 🌙 **Life Rhythm & Sleep Schedule Simulation**: Students adhere to personalized sleep and wake schedules (differing across weekdays and weekends, with regular vs irregular habits). Messages sent during sleep are held and automatically replied to upon waking (toggleable in Settings).
- 💬 **Faithful MomoTalk Experience**: Real-time "..." typing animation with comfortable reading pacing, "Read" (既読) receipts for Sensei's messages, message timestamps, and day dividers.
- 📸 **Multimodal Vision**: Send photos or drawings to students; students look at the image contents and react in-character.
- 💖 **Kizuna Relationship Rank**: Interactive chatting increases your relationship rank (Lv.1+) with each student, tracked with celebratory rank-up sound effects.
- 🌐 **5-Language Internationalization**: Full UI and in-app user guides in Japanese, English, Korean, Simplified Chinese, and Traditional Chinese.
- 🖼️ **One-Click Screenshot Export**: Save your chat history as a high-resolution PNG image directly from the sidebar.
- 📱 **Responsive Design**: Flawlessly adapts to desktop layouts and mobile viewports.

## 🚀 Quick Start

### Online Demo
- Repository: [hirarara74/momotalk_AI](https://github.com/hirarara74/momotalk_AI)

### Local Development

```bash
# Clone the repository
git clone https://github.com/hirarara74/momotalk_AI.git
cd momotalk_AI

# Install dependencies
npm install

# Start Vite development server
npm run dev

# Run unit tests
npm test

# Build for production
npm run build
```
