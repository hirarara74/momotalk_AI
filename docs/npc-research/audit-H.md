# 監査 H: ヒカリ(10117)・ノゾミ(10118)

依頼: 「ヒカリとチャットしたらキャラと違う気がする」。

## 原因
`rosterExtra.ts` のヒカリが「丁寧で落ち着いた小声の敬語（です・ます）、感情を出さない」になっていた。ゲーム内ボイスと各百科の記述は、間延びしたタメ口（語尾を「〜ねー」「〜のー？」と伸ばす）で、子供っぽく、お菓子好きで、甘えん坊でサボり好き、というキャラである。Fandom の Personality 欄だけが "polite and calm, soft-spoken" と書いており、設定はこれを字面通りに採って敬語にしてしまったとみられる。
あわせて、全言語の挨拶とセリフ例に「↑↑↓↓←→←→」が入っていた。実チャットで「こんにちは」に対して英語・中国語・日本語の返信にそのまま出た。アリ観察と運転は、公式の趣味ではあるが、会話例が敬語＋その2つに偏っていて、質問ごとに繰り返された。

## 変更後も残る問題（実チャットで確認した事実）
1. 名前の言語ずれ: zh/tw で「ノゾミ」が「诺兹米」「诺望」「諾茲米」、kr で「노즈미」、en で学園名「Hyakkiyako」を作る。ヒカリ・ノゾミ個別の問題ではなく、下記の共通パイプラインが原因。
2. zh で「最近玩游戏吗？」に対し、挨拶（Voice reference）をそのまま返した例があった（変更前から傾向あり）。下記パイプラインが原因。
3. jp でノゾミを「お姉ちゃん」と呼んだ例（relations に追記して以降は再確認していない）。kr で「더럽게」という強い言い回しが 1 回出た。モデルの揺れで、設定側では防ぎきれない。
4. 返信の長さ・言語（tw 質問に簡体字が混ざった例が変更前にあった）はモデル依存で、変更後の tw は繁体字だった。

## 共通パイプラインの原因と修正案（編集していない）
- `prompts.ts` の `getVoiceTransferDirective` が、キャラの挨拶を「Voice reference」として全言語の指示に入れている。挨拶がそのままオウム返しされる傾向がある（zh のゲーム質問）。修正案: 「挨拶の文面をそのまま繰り返さない」を指示に1文足す、または挨拶ではなく voice の要約を渡す。
- 非日本語の system prompt は、プロフィールが日本語のまま（`localizeProfile` は一部の語句だけ置換）。人名・学園名が日本語表記で入るため、モデルが zh/tw/kr で名前を自作する。修正案: `names` の各言語表記（ノゾミ → 望/希望/노조미/Nozomi）を、プロンプトの「関係性」に近い所へ列挙して「他の生徒の名前はこの表記を使う」と指示する。
- ここで直した語調は `*セリフ例` にも依存する。会話例が挨拶の暗号のような「記号だけの1行」を含む設定は、同じ事故（記号のオウム返し）を起こしやすい。他の生徒でも「記号だけの lines」を探す価値がある（`grep "↑↑↓↓" src` で現在はヒカリ関連の残りなし）。
