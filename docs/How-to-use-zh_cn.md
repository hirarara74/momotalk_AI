# MomoTalk AI 使用说明

MomoTalk AI 是一款还原《蔚蓝档案》MomoTalk 界面的沉浸式 AI 对话 Web 应用。借助现代大语言模型（LLM），老师可以与基沃托斯的 23 位学生展开实时、自然的深度互动。

---

## 📚 界面与功能

### 1. 学生列表（左侧边栏）
- **选择学生**: 点击左侧列表中的学生即可开启专属对话。
- **筛选与搜索**:
  - **学院图标**: 按学院（阿拜多斯、歌赫娜、三一、千禧年等）筛选学生。
  - **搜索栏**（快捷键 `/`）: 支持学生姓名、罗马拼音、常用昵称实时搜索。
- **最新消息预览**: 列表直接展示每位学生的最新留言与回复状态。
- **睡眠状态标记（💤）**: 学生处于就寝时间时，头像右上角会亮起「💤」图标。

### 2. 对话界面
- **发送消息**: 在底部输入框输入内容后按 `Enter` 键发送。
  - 换行请按 `Shift + Enter`。
- **正在输入动画**: 老师发送消息后，学生端会呈现逼真的“...”打字气泡。
- **已读标记（既読）**: 老师发送的消息会在学生接收处理后标注「既読」。
- **多模态图片识别**:
  - 支持点击回形针图标或拖拽图片发送。
  - 学生具备视觉理解能力，能够根据图片内容结合自身人设给出个性化反应。

### 3. 作息与睡眠模拟
- 每位学生均拥有符合原作设定的作息时间表（区分工作日/节假日起床时间，以及规律/熬夜作息）。
- **睡眠期间交互**:
  - 在学生睡眠期间发信，消息会被留存；当学生在起床时间醒来后，会自动主动向老师发送回复。
  - 该功能可在「设置」中随时开启或关闭。

### 4. 羁绊等级系统
- 经常与学生交流可提升好感度并提升羁绊等级（Kizuna Rank）。
- 升级时将播放原作经典的羁绊升级结算音效与动效。

### 5. 侧边栏底部操作
- **🌐 切换语言**: 支持中文（简体/繁体）、日文、英文、韩文即时切换。
- **🧹 清空对话**: 重置当前学生的聊天记录。
- **💾 导出长图**: 一键将当前对话记录渲染并下载为高清 PNG 图片。

## ⚙️ 系统设置（右上角齿轮）

点击右上角齿轮图标可打开设置窗口：

1. **AI 服务商选择**:
   - **Groq**（推荐・默认）: 极速推理，支持 `openai/gpt-oss-120b` 与 `qwen/qwen3.8-27b`。
   - **Google Gemini**: 谷歌多模态大模型。
   - **OpenAI 兼容接口**: 接入任意兼容第三方中转或自定义模型。
   - **Anthropic Claude**: 卓越的叙事表达模型。
2. **作息模拟开关**: 自由启用或禁用学生睡眠作息机制。
3. **界面主题**: 支持在 MomoTalk 原版主题与 YuzuTalk 风格间切换。
4. **全屏显示**: 沉浸式全屏浏览体验。
