# アロナ・プラナの会話対応

既存の一覧データにあるアロナ（104）とプラナ（173）を、専用プロンプト・対応判定・多言語の初回挨拶へ登録した。アイコンや会話履歴は既存のIDを使い、新しい人物として重複させない。

- アロナ: 明るく親しみのある丁寧語。プラナを「プラナちゃん」と呼ぶ。
- プラナ: 落ち着いた簡潔な丁寧語。アロナを「アロナ先輩」と呼ぶ。
- 英語の `Plana` / 一覧の `Purana`、韓国語の `A.R.O.N.A`、中国語・繁体字の名前でも同じ人物として扱う。
- 学園の通常の生徒として学年・部活・銃を作らず、ゲームの設定や募集結果を実際に操作したとも断定しない。既存の共通指示と共有記憶への対策を適用する。
- 既存の睡眠・アイコン選択・会話保存の仕組みを使用。アプリ用の生活リズムと画像生成用プロフィールも登録した。アロナの既存画像用ID（9999）と一覧ID（104）は同じ外見を参照する。
