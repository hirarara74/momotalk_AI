# MomoTalk AI 使い方ガイド

MomoTalk AI は、『ブルーアーカイブ』に登場するチャットアプリ「モモトーク」を再現した対話型AIWebアプリケーションです。最新のLLM（大規模言語モデル）を活用し、キヴォトスの生徒たちとリアルタイムに自然な会話を楽しむことができます。

---

## 📚 基本機能と画面構成

### 1. 生徒一覧（サイドバー）
- **生徒の選択**: 左側の生徒一覧から会話したい生徒をクリックします。
- **絞り込みと検索**:
  - **学校アイコン**: 学園別（アビドス、ゲヘナ、トリニティ、ミレニアムなど）に生徒をフィルタリングします。
  - **検索バー**（ショートカットキー `/`）: 生徒の名前や読み仮名、愛称で絞り込みが可能です。
- **最新メッセージプレビュー**: 生徒一覧には各生徒との最新メッセージが表示され、返信状況が一目で分かります。
- **睡眠バッジ（💤）**: 生徒が就寝中の時間帯は、生徒アイコン右上に「💤」バッジが表示されます。

### 2. チャット画面
- **メッセージの編集・送信取り消し**: PCではメッセージを右クリック、モバイルでは長押しするとメニューが開きます。先生・生徒どちらのメッセージも編集・削除できます。「⋯」ボタンからも操作でき、編集／削除内容は保存されます。
- **メッセージの送信**: 画面下部の入力欄にメッセージを入力し、`Enter` キーまたは送信ボタンをクリックします。
  - 改行は `Shift + Enter` です。
  - 日本語入力で変換を確定する `Enter` では送信されません。
- **入力中アニメーション**: 先生がメッセージを送信すると、生徒がチャットルームでメッセージを入力しているリアルな「...」インジケーターが表示されます。
- **既読（Read）機能**: 先生の送信したメッセージには、生徒が読んだことを示す「既読」マークが表示されます。
- **画像の送信（マルチモーダル認識）**:
  - 入力欄の右にある画像アイコンから選ぶか、画像を貼り付け（`Ctrl + V`）て送信できます。
  - 生徒は画像の内容を視覚的に理解し、生徒自身のキャラクターに応じた感想やコメントを返してくれます。
- **スタンプ**: 入力欄の左のアイコンからスタンプ一覧を開き、タップして送信します。一覧の下の「1」「2」でページを切り替えられます。生徒はスタンプの意味（「OK」「ありがとう」、驚き・照れ など）を理解して返事をします。
- **プロフィールを見る**: チャット画面の生徒アイコン（画面上部・メッセージ横）をタップすると、その生徒のプロフィールが開きます。

### 3. 生活リズム＆睡眠シミュレーション
- 生徒には原作設定に基づいた個別の就寝・起床時間が設定されています。
- 平日と休日で起きる時間が変わる生徒や、規則正しい生徒、夜更かしがちな生徒など、個性的な生活リズムを再現しています。
- **睡眠中の動作**:
  - 生徒が寝ている時間帯にメッセージを送ると、生徒はすぐには返信せず、翌朝の起床時間になると自動でメッセージを読んで返信してくれます。
  - 睡眠機能は「設定」モーダルからいつでもオン/オフを切り替えることができます。

### 4. 絆ランク（Kizuna Rank）
- 生徒とたくさんお話しすることで、生徒との親密度が深まり「絆ランク」が上がります。
- 絆ランクがアップすると、ゲーム本編でおなじみの演出と効果音が再生されます。

### 5. サイドバー下部のアクション
- **🌐 言語切り替え**: 日本語、英語、韓国語、簡体字中国語、繁体字中国語を即座に切り替え。
- **🧹 会話のリセット**: チャット画面右上の「リセット」ボタンで、その生徒との会話履歴を消去できます（確認画面が出ます）。

## ⚙️ 設定（歯車アイコン）

画面右上の歯車アイコンをクリックすると設定モーダルが開きます。

1. **AIプロバイダー選択**:
   - **Groq**（推奨・デフォルト）: 超高速推論。`openai/gpt-oss-120b` や `qwen/qwen3.8-27b` などを選択可能。
   - **Google Gemini**: Googleの最新マルチモーダルモデル。
   - **OpenAI 互換**: 任意のOpenAI互換エンドポイントやカスタムモデルを利用可能。
   - **Anthropic Claude**: 高度な日本語表現力を持つClaudeモデルを利用可能。
2. **睡眠モードの切り替え**: 生徒の生活リズムシミュレーションの有効/無効を設定。
3. **基本設定**: 効果音のオン/オフと音量、全画面表示、ズーム、会話のドラッグ操作を設定できます。
